# Dungeon and raid plans

Generated by `go run ./tools/dungeongen -spec tools/dungeongen/plans.json -out-dir dungeons -table docs/PLANS.md` from the spec
(tools/dungeongen/plans.json) and the plan files in dungeons/; a test fails when this file is out of date. Do not edit the tables by hand: edit the spec and regenerate.

Every dungeon and raid of the server has a plan (`dungeons/<name>.json`, format: README "Dungeon plans"), the single data source of the agent's modes and of
TortoiseBots self-clear. Most are **drafts**: the legs, pull groups, bosses, entrance, portal, level band and hired party come from the world
database export alone (`tools/dungeongen/export.sh`, one folder per map under `tools/dungeongen/testdata/map<id>`), with the usual boss order from game knowledge. A draft
has not had its **mapping walk** (a GM-invisible walk of the route before the first live run, AUTO-IMPROVE step 0), so its waypoints, pull order, doors and events are
unchecked; `dungeon_run` refuses it unless `allow_draft` is passed, and refuses raid plans (no raid driver yet).

**Needs besides killing** is read from the game object and item names of the core's instance scripts (`src/scripts/dungeons/<dungeon>`) and from vanilla knowledge; none of it has been walked
or run, so treat it as the checklist for the mapping walk, not as a verified list. "No spawn row" means the boss is summoned by a script and is not in a leg.

Status: `draft` (not mapped, not live-checked), `mapped` (the route corrected from a mapping walk), `live-checked` (run live by a party). A plan's `status` field is the truth;
this table is read from it.

**mmaps.** The navmesh tests (path_to, the waypoint and pack checks) run only where the machine has the map's `<map>.mmap` and `<map>*.mmtile` files
(`$TURTLE_AGENT_MMAPS`, `~/tb-ci/mmaps-turtle<map>` or `~/tortoise-wow-server/data/mmaps`). The test VM (yulon-ubuntu2) holds all 40 instance maps and map 1 (Kalimdor, the outer map of the
portals of Zul'Farrak and most Kalimdor dungeons), one folder each; the source is m910q's `~/tortoise-wow-server/data/mmaps` (about 0.5 GB of tiles, 2.5 GB with the continents).
To add a map: `rsync -a m910q:tortoise-wow-server/data/mmaps/<map>.mmap m910q:tortoise-wow-server/data/mmaps/<map>*.mmtile ~/tb-ci/mmaps-turtle<map>/`.
The outer maps 0 (Eastern Kingdoms) and 1 are needed only for the portal point checks.

**Points on the navmesh.** A spawn may stand where the mesh has no floor (over lava or water, on a ledge, in the air). `tools/dungeongen/snaps.json` moves such a point of a draft to the nearest
walkable floor on the same level (within 5 yd sideways and 3 yd up or down, the floor at or below the point first) and the generator applies it; rebuild it from the mesh with
`go run ./tools/dungeongen -spec tools/dungeongen/plans.json -snap-update ~/tb-ci` (needs the mmaps folders). A point with no such floor keeps its spawn position and carries `needs_walk`
(on the leg for its `to`, on the pull group, on the boss); the mapping walk has to find the real waypoint, and the navmesh sweep (TestPlansOnNavmeshWhereTheMachineHasIt) skips exactly those. Pull
positions are the creatures' own, so one up to 4 yd off the floor or 2.5 yd to the side is left as it is.

## Order of the mapping walks

A mapping walk turns a draft into a mapped plan (README: the map-first rule). Recommended order, by value for the Uldaman goal and for how much of the draft is a guess:

1. **The dungeons of the Uldaman/ZF level band and below, one wing at a time, easiest layout first**: Razorfen Downs, Maraudon (orange, purple), Sunken Temple, Scarlet Monastery wings (graveyard, library, armory, cathedral), Razorfen Kraul, Gnomeregan. They have the plainest routes and the groups
   the hired-party standard (blue gear, all spells) is easiest at.
2. **Low dungeons** (Ragefire Chasm, Deadmines, Wailing Caverns, Shadowfang Keep, Blackfathom Deeps, Stockade): short, good for exercising the draft-to-mapped workflow itself; each needs its events noted in the table (Deadmines cannon, WC Naralex, BFD shrine, SFK doors).
3. **Blackrock Depths, Lower Blackrock Spire, Stratholme (live, undead), Scholomance, Dire Maul (east, west, north)**: large; do them wing by wing, the keys and events in the table decide the walk's checklist.
4. **Turtle custom dungeons** in level order (Frostmane Hollow, Windhorn Canyon, Crescent Grove, Dragonmaw Retreat, Stormwrought Ruins, Gilneas City, Hateforge Quarry, Karazhan Crypt, Stormwind Vault, Black Morass): their layouts are the least known, so the walk teaches the most; their scripts live in the core under src/scripts/dungeons.
5. **Raids last** (Onyxia, Molten Core, Zul'Gurub, Ruins of Ahn'Qiraj, Blackwing Lair, Upper Blackrock Spire, Lower Karazhan Halls, Timbermaw Hold, Temple of Ahn'Qiraj, Emerald Sanctum, Naxxramas, Upper Karazhan Halls): no raid driver exists yet, and a raid walk needs a group of GM-invisible walkers only for the route, which the draft legs already give per boss.
